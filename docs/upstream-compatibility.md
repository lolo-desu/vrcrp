# 官网适配

客户端直接运行官网当前前端，保留其页面、操作、权限限制与服务器结果。新增适配只补齐系统导航、通知、主题和缓存之间的衔接。

2026-10-05 检查范围：所有公开前端模块与路由，重点包括排行榜、悄悄喜欢，以及聊天搜索、分组和置顶。

- 排行榜请求 `/api/v1/browse`，保留官方顺序、筛选、分页和只读限制。客户端无法从公开前端确认服务器的具体评分公式，不自行计算排名。
- 悄悄喜欢使用官网的长按处理、功能权限和 `/api/v1/swipes` 的 `secret` 参数；新列表 `/likes/secret`、升级与取消操作同步缓存。
- 聊天查询键包含状态、分组和搜索条件。全局摘要只更新过滤列表已有的行，不替换其成员、顺序或分页；已读同步覆盖各列表变体。
- 官网提供分组与置顶接口后，聊天长按调用原菜单，不再用本地样式重新排序。迁移只处理当前账户已加载的旧置顶，成功后再清除本地记录。

验证使用官网下载的公开前端，所有账户数据、API 操作和 WebSocket 都由测试替身提供，不访问真实账户。`scripts/fetch-upstream-ui.py` 下载测试资源，`scripts/test-upstream-ui.py` 在 Chromium 和 WebKit 执行长按、取消、权限、导航、分组、置顶、主题和官方排名顺序检查；资源不会打包进安装包。

官网会拒绝 GitHub 构建机的直接访问，因此 Actions 使用经 SHA-256 校验的公开前端测试快照，运行相同的完整浏览器验证。需要检查之后的官网更新时，运行不带 `--snapshot` 参数的下载脚本获取当前版本。
